## 📊 核心优势

### 1. 预分配节点架构（设计阶段理论分析）

**设计阶段假设**：扫描路径可能接近 68 秒级别，且约 98.5% 的时间可能集中在排序阶段

**方案**：
```cpp
// 预分配（有序）
for (auto& file : files) {
    nodes.push_back({.data = {}, .needsScan = true});
}

// Worker 填充（无返回）
workerPool.submit([&nodes](Task t) {
    nodes[t.nodeIndex].data = scan(...);
});

// 无需排序！
workerPool.waitAll();
```

**设计阶段理论预期**：约 136x 的潜在加速（68 秒 → 0.5 秒，属于设计/分析口径，不是最终实测）
