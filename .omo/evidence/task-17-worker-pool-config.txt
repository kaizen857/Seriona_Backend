Implementation notes:
- Added public tuning helpers `getOptimalWorkerCount()` and `getOptimalTagReaderLimit(std::size_t)` while keeping `BS::thread_pool`, `std::counting_semaphore<>`, pending futures, mutexes, and atomics private in the pimpl implementation.
- `ScannerWorkerPool::Config` now normalizes zero worker count to detected hardware concurrency with a fallback of 1, normalizes zero tag-reader slots through the optimal helper, and caps tag-reader slots to the normalized worker count.
- Added cooperative `cancel()`: it marks the pool cancelled, stops accepting new non-empty submissions, waits pending futures to finish, collects task errors, and clears the internal pending future vector. It does not force-stop running tag-reader work.
- `waitAll()` now drains all pending futures, returns successful and failed `WorkerResult` entries, and stores aggregate `ScannerError` values for `errorsSnapshot()` instead of letting one thrown task abort result collection.
- Preserved cache-hit bypass, tag-reader semaphore limit, stats snapshot counters, batch submission in chunks of 64, and pool reuse after ordinary success/failure. A cancelled pool intentionally remains cancelled.
- Updated prior process/batch exception tests to the new task-17 error aggregation contract.
