# Task 27 Scanner Performance Evidence

Generated with public-domain-safe synthetic `.flac` text fixtures and a fake `TagMetadataReader` seam.

## Commands

```sh
cmake --build build --target seriona_scanner_perf_test
build/tests/seriona_scanner_perf_test --output .omo/evidence/task-27-perf-report.md
```

## Metric Notes

- `phase breakdown`: captured from the production scanner spdlog performance block for each run.
- `cache hit rate`: derived from `filesSkipped / filesDiscovered` in `ScanProgress`.
- `TagReader calls/time`: measured in the benchmark fake `TagMetadataReader`; this is the scanner seam time, not real TagReaderCore parsing.
- `cumulative worker time`: captured from production scanner logs as worker hash ms and worker TagReader parse ms.
- Incremental runs mutate one changed file, one added file, and one deleted file after warm cache. The harness updates the V3 scan-root sidecar hash to force the existing incremental execution path for this shape, matching prior Phase 3 integration-test practice.

## Adversarial Checks

- `stale_state`: benchmark source and CMake registration were reread after edits, then the exact built target was rerun.
- `dirty_worktree`: task edits are limited to scanner benchmark harness/registration and `.omo` evidence/notepad files.
- `misleading_success_output`: this report is generated by the benchmark executable from observed run data.
- `hung_or_long_commands`: each scan waits for `ScanCompleted` with a 600 second timeout; no timed-out scan is recorded as success.
- `flaky_tests`: correctness is based on deterministic generated fixture counts; timing values are raw observations and may vary.
