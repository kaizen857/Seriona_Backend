Implementation notes
- Added scanner-local `ScanModeDecision` and `decideScanMode()` in `file_scanner_orchestrator.cpp`.
- Decision inputs are `computeDirectoryTreeHash(rootPath)` plus `SQLiteCacheV3::loadScanRoot(rootPath)`.
- Explicit `ScanMode::Full` returns Full before any cache downgrade can happen.
- Missing directory-tree hash, absent scan-root row, changed hash, or V3 cache open/load error returns deterministic Full.
- Matching cached `directoryTreeHash` returns Incremental.
- `runScan()` records the selected mode and directory-tree hash through `SQLiteCacheV3::updateScanRoot()` after the existing full-root reconcile path completes.
- Incremental classification/execution is intentionally not implemented: `reconcileRoot()` still processes the root through the existing path for both decisions.
- Because the active runtime cache is still V2, V3 scan-root state is stored in `<database>.scan-roots-v3.sqlite` to avoid migrating the active V2 runtime DB before tasks 24/25.
