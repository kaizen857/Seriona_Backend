- Added private `IncrementalScanPlan` with `deleted`, `added`, and `changed` lists in `file_scanner_orchestrator.cpp`.
- Added private `planIncrementalScan(rootPath, fileSystemEntries, cachedLocations)`.
- The helper indexes cached V3 `CachedLocation` rows by normalized file path, scoped to the requested root path.
- Added/current entries are based on current filesystem audio candidates from `ClassifiedPath` (`AudioCandidate` and `SingleFileRoot`).
- Changed detection recomputes the existing `computeLocationId(entry.path, file_size, fileMtime(entry.path))`; no second identity rule was introduced.
- Deleted detection returns cached locations whose normalized path was not observed in current filesystem candidates.
- `reconcileRoot()` and `runScan()` execution behavior were not changed for task 24; no pruning and no worker submission are connected to the plan.
