Implemented behavior:
- Added backward-compatible `ScannerConfig` fields: `workerCount`, `tagReaderConcurrency`, `enableIncrementalScan`, and `forceFull`.
- Runtime effective config resolves `0` worker/tagreader values to previous automatic defaults.
- `SERIONA_SCANNER_WORKERS` and `SERIONA_SCANNER_TAGREADER_CONCURRENCY` override configured concurrency when they contain positive integers.
- `SERIONA_SCANNER_DISABLE_CONCURRENCY=1` wins over both override env vars and forces one worker plus one TagReader slot.
- Malformed env values are not silent: the runtime logs a warning and falls back to the configured/default value.
- `enableIncrementalScan=false` and `forceFull=true` force Full mode before scan-mode decision, without changing the existing `scan(..., ScanMode)` API.

Docs:
- `docs/file-scanner.md` now documents all ScannerConfig fields, env var precedence, defaults, examples, and malformed-value fallback behavior.
